# Avaluació

## Resultats d'aprenentatge i pesos

| Resultat d'aprenentatge | Pes |
| --- | ---: |
| RA1. Implanta arquitectures web analitzant i aplicant criteris de funcionalitat. | 10 % |
| RA2. Implanta aplicacions web en servidors web amb criteris de configuració i seguretat. | 20 % |
| RA3. Implanta aplicacions web en servidors d'aplicacions amb criteris de configuració i seguretat. | 20 % |
| RA4. Administra servidors de transferència d'arxius garantint la disponibilitat del servei. | 20 % |
| RA5. Verifica l'execució d'aplicacions web configurant els serveis de xarxa necessaris. | 15 % |
| RA6. Elabora documentació amb eines de generació, control de versions i integració contínua. | 15 % |

La nota final és la mitjana ponderada dels sis RA. Per superar el mòdul cal obtindre almenys el 50 % i superar tots els RA, d'acord amb la programació didàctica.

## Evidències i instruments

Cada criteri d'avaluació es treballa amb una o més activitats. Es poden utilitzar rúbriques, llistes de comprovació, portafolis, observació directa, proves escrites o pràctiques, pràctiques de taller, autoavaluació i coavaluació.

En les activitats de desplegament es valorarà especialment que:

- el servei funcione i es puga comprovar;
- la configuració siga reproduïble i segura;
- les decisions estiguen justificades;
- la documentació permeta a una altra persona repetir el procés;
- la resolució d'errors es base en proves i logs.

## UP1 i RA1

La UP1 treballa els criteris RA1.a, RA1.b, RA1.c, RA1.d, RA1.e, RA1.h i RA1.i, d'acord amb la seqüenciació de la programació didàctica. Els criteris RA1.f i RA1.g també poden aportar evidències en el període de formació en empresa, tal com preveu la programació. La [teoria completa i l'itinerari de la UP1](up1/index.md) inclouen preguntes de comprovació i orientacions per preparar les evidències de disseny, desplegament i verificació. Aquestes preguntes són un recurs d'estudi no qualificable.

## Recuperació

Si no se supera un criteri, el professorat pot proposar una recuperació en el format i la data comunicats prèviament. En la convocatòria ordinària es recuperen els criteris no superats del RA corresponent. Si s'ha perdut l'avaluació contínua, la prova inclou tots els RA. La convocatòria extraordinària inclou els RA no superats, segons la programació.

Les absències que coincidisquen amb un instrument d'avaluació s'han de justificar per poder recuperar-lo. La formació en empresa aportarà evidències indirectes mitjançant seguiment tutorial, documentació, repositoris, observacions i reflexions de l'alumnat.
