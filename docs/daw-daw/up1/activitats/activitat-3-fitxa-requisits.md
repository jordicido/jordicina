# Activitat 3. Fitxa de requisits i decisió tècnica

## Repte

Tria un dels casos següents i prepara la decisió d'arquitectura per a una primera implantació:

- un blog personal amb contingut estàtic;
- una botiga amb catàleg i autenticació;
- una API per a una aplicació mòbil;
- una intranet de gestió de reserves.

## Tasques

1. Escriu entre cinc i huit requisits funcionals i no funcionals.
2. Indica els components i les comunicacions que necessitaries.
3. Compara dues alternatives d'arquitectura.
4. Tria una alternativa i justifica-la per cost, complexitat, seguretat i manteniment.
5. Defineix quatre proves d'acceptació que permeten decidir si el desplegament està preparat.

## Criteris de revisió

- Els requisits són concrets i es poden comprovar.
- La solució respon al cas i no només enumera tecnologies.
- La decisió explica compromisos i limitacions.
- Les proves tenen resultat esperat i evidència prevista.
