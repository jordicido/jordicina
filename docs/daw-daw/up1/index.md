# UP1. Itinerari de les arquitectures web

Aquesta unitat recorre el camí que va des del model d'una aplicació fins a un primer servei web verificat i documentat.

## Itinerari de la teoria

| Apartat | Pregunta principal |
| --- | --- |
| [1. Models d'arquitectura](01-models-arquitectura.md) | Com es reparteixen les responsabilitats d'una aplicació? |
| [2. Protocols i recorregut](02-protocols-recorregut.md) | Què passa quan una persona obri una URL? |
| [3. Servidors web i d'aplicacions](03-servidors-web-aplicacions.md) | Quin component rep, processa i respon cada petició? |
| [4. Virtualització i contenidors](04-virtualitzacio-contenidors.md) | Com aïllem i reproduïm els serveis? |
| [5. Requisits i documentació](05-requisits-documentacio.md) | Com definim i demostrem que el desplegament és correcte? |

## Seqüència de 7 hores

| Sessió | Treball principal | Evidència |
| ---: | --- | --- |
| 1 | Models, components i recorregut d'una petició | Esquema client-servidor |
| 2 | Protocols, servidors i requisits | Taula de decisions |
| 3 | Contenidors i desplegament mínim | Proves HTTP i registre d'incidències |
| 4 | Documentació i síntesi | Producte final i autoavaluació |

## Activitats

| Activitat | Què fareu? | Organització |
| --- | --- | --- |
| [1. Mapa d'arquitectura](activitats/activitat-1-mapa-arquitectura.md) | Representar el recorregut d'una petició i justificar els components. | Parelles · 1 h 30 min |
| [2. Desplegament mínim](activitats/activitat-2-desplegament-minim.md) | Posar en marxa un servei i verificar-lo amb proves reproduïbles. | Parelles · 2 h |
| [3. Fitxa de requisits](activitats/activitat-3-fitxa-requisits.md) | Escollir una arquitectura per a un cas i defensar-la. | Equips · 2 h |
| [Autoavaluació](activitats/autoavaluacio.md) | Comprovar individualment els conceptes abans de lliurar. | Individual · 30 min |

## Producte final

Integra el mapa, la fitxa de requisits i les proves del desplegament en un únic document. Una altra persona ha de poder entendre l'arquitectura, repetir el desplegament i comprovar el resultat.
