# UP1. Del problema al programa en funcionament

## Presentació

En aquesta unitat seguirem el recorregut que va des d’una necessitat fins a un programa en funcionament. Coneixerem el sistema on s’executa, els llenguatges i tipus de codi, les eines, les fases del desenvolupament, els equips i les metodologies de treball.

## Què aprendràs

- Relacionar un programa amb el processador, la memòria, l’emmagatzematge i els perifèrics.
- Diferenciar codi font, objecte, intermedi i executable.
- Classificar llenguatges de programació segons diversos criteris.
- Identificar la funció de les eines principals del desenvolupament.
- Ordenar les fases d’un projecte i reconéixer els perfils d’un equip.
- Diferenciar enfocaments predictius, iteratius, incrementals i àgils.
