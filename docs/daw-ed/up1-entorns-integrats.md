# UP1. Entorns integrats de desenvolupament

## Presentació

En aquesta unitat instal·larem, configurarem i compararem dos entorns integrats de desenvolupament (IDE): **Visual Studio Code** i **IntelliJ IDEA**. El fil conductor serà aquesta pregunta professional:

> **Com podem preparar un entorn de desenvolupament reproduïble que permeta editar, construir i mantindre programes?**

Un IDE reuneix un editor, eines de construcció, depuració, gestió de projectes i extensions en una mateixa interfície. Compararem un entorn lleuger i extensible amb un entorn orientat a projectes Java i a la integració de ferramentes. Per cobrir la construcció de llenguatges diferents utilitzarem Java i Kotlin en IntelliJ IDEA; el projecte principal es mantindrà en Java amb Maven.

## Què aprendràs

- Instal·lar i verificar Visual Studio Code i IntelliJ IDEA, respectant l’edició i la llicència de cada instal·lació.
- Afegir, configurar i eliminar mòduls, connectors i extensions.
- Personalitzar l’editor i automatitzar tasques habituals del projecte.
- Configurar canals d’actualització i comprovar la compatibilitat abans d’actualitzar.
- Generar artefactes Java i Kotlin en un mateix IntelliJ IDEA.
- Construir el mateix projecte Java amb Visual Studio Code i IntelliJ IDEA i comparar el resultat.
- Identificar característiques comunes i específiques de diversos entorns.
- Deixar una guia de reproducció amb versions, ordres, proves i incidències.

## Resultat d’aprenentatge i criteris

**RA2.** Avalua entorns integrats de desenvolupament, analitzant les seues característiques per a editar codi font i generar executables.

| Criteri | Què hauràs de demostrar |
| --- | --- |
| **RA2.a** | Instal·lar entorns de desenvolupament, propietaris i lliures. |
| **RA2.b** | Afegir i eliminar mòduls a l’entorn de desenvolupament. |
| **RA2.c** | Personalitzar i automatitzar l’entorn de desenvolupament. |
| **RA2.d** | Configurar el sistema d’actualització de l’entorn de desenvolupament. |
| **RA2.e** | Generar executables a partir de codi font de diferents llenguatges en un mateix entorn de desenvolupament. |
| **RA2.f** | Generar executables a partir d’un mateix codi font amb diversos entorns de desenvolupament. |
| **RA2.g** | Identificar les característiques comunes i específiques de diversos entorns de desenvolupament. |

## Abans de començar

Consulta la llicència i els requisits de cada producte. En el laboratori treballarem amb Visual Studio Code i IntelliJ IDEA; la fitxa indicarà si IntelliJ IDEA funciona amb les funcions bàsiques gratuïtes o amb les funcions avançades d’Ultimate mitjançant subscripció o llicència educativa. No instal·les programari d’origen dubtós ni actives llicències amb claus compartides. Treballa amb projectes de prova, no publiques credencials i conserva les versions i les ordres que permeten repetir el laboratori.
