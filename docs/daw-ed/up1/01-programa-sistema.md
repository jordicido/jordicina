# 1. El programa informàtic i el sistema

## Què és un programa?

Un **programa informàtic** és un conjunt ordenat d’instruccions que indica a un sistema com ha de realitzar una tasca. Les instruccions poden calcular, guardar dades, mostrar informació, comunicar-se amb altres sistemes o prendre decisions.

Una aplicació pot estar formada per un únic programa o per diversos components que treballen conjuntament. Per exemple, una aplicació web pot incloure una interfície, un servidor i una base de dades.

| Concepte | Significat | Exemple |
| --- | --- | --- |
| Programa | Instruccions preparades per executar-se | Un script de còpia |
| Aplicació | Programa o conjunt de programes amb una finalitat | Un gestor de reserves |
| Procés | Programa que està executant-se | El navegador obert |

## Programari de sistema i d’aplicació

El **programari de sistema** administra els recursos de l’ordinador i ofereix serveis a altres programes. En formen part el sistema operatiu, els controladors, les utilitats i alguns entorns d’execució.

El **programari d’aplicació** permet a l’usuari resoldre una necessitat concreta: navegar, editar documents, gestionar una botiga, reproduir vídeo o consultar una base de dades.

## Components que intervenen

- **Emmagatzematge:** conserva el programa i les dades encara que l’equip s’apague.
- **Memòria RAM:** manté temporalment les instruccions i les dades que s’estan utilitzant.
- **Processador:** interpreta i executa les instruccions.
- **Sistema operatiu:** administra memòria, processos, fitxers i dispositius.
- **Perifèrics:** permeten introduir dades i mostrar resultats.
- **Xarxa:** connecta el programa amb serveis i dades remotes.

## Què passa quan executem un programa?

1. L’usuari o un altre programa sol·licita l’execució.
2. El sistema operatiu localitza el programa en l’emmagatzematge.
3. Carrega les instruccions i les dades necessàries en la RAM.
4. Crea un procés i assigna recursos del sistema.
5. El processador executa les instruccions.
6. El programa rep entrades i produeix resultats.
7. Quan acaba, el sistema allibera els recursos.
