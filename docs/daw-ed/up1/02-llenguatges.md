# 2. Llenguatges de programació

## Què és un llenguatge?

Un llenguatge de programació és un sistema formal que permet descriure dades, instruccions i processos. Perquè un programa siga vàlid, ha de respectar el vocabulari, la sintaxi i el significat definit pel llenguatge.

També pot oferir tipus de dades, estructures de control, funcions, classes i biblioteques. Les ferramentes del llenguatge ajuden a escriure, traduir, provar i executar el programa.

## Segons el nivell d’abstracció

- **Baix nivell:** pròxim al processador. Inclou el llenguatge màquina i l’assemblador. Permet un control molt directe, però és més difícil de llegir i mantenir.
- **Alt nivell:** utilitza construccions més pròximes al raonament humà. Python, Java, JavaScript, PHP, Kotlin i C# en són exemples.

## Segons el paradigma

- **Imperatiu:** descriu una seqüència d’ordres.
- **Procedimental:** organitza el programa en procediments o funcions.
- **Orientat a objectes:** agrupa dades i comportament en objectes.
- **Funcional:** treballa amb funcions i transformacions de dades.
- **Declaratiu:** descriu el resultat que es vol obtindre; SQL n’és un exemple.

Un llenguatge pot combinar diversos paradigmes. Per això convé parlar del paradigma habitual, no d’una etiqueta absolutament exclusiva.

## Segons la forma d’execució

- **Compilat:** el codi es tradueix abans de l’execució.
- **Interpretat:** un entorn gestiona l’execució a partir del codi font.
- **De codi intermedi:** es genera una representació que després executa una màquina virtual.
- **Híbrid:** combina diverses tècniques.

| Llenguatge | Paradigma habitual | Execució habitual | Ús freqüent |
| --- | --- | --- | --- |
| Java | Orientat a objectes | Bytecode sobre JVM | Aplicacions empresarials |
| Python | Multiparadigma | Intèrpret o màquina virtual | Automatització, dades i web |
| JavaScript | Multiparadigma | Navegador o Node.js | Aplicacions web |
| C | Procedimental | Compilació | Sistemes i programari de base |
| SQL | Declaratiu | Interpretat pel SGBD | Bases de dades |

!!! tip "Pregunta de control"
    Per què no és suficient dir que un llenguatge és simplement “compilat” o “interpretat”?
