# Activitat 1. Laboratori d’instal·lació

## Finalitat

Instal·lareu **Visual Studio Code** i **IntelliJ IDEA** i deixareu una fitxa que permeta repetir el procés. Treballareu principalment el criteri **RA2.a**.

## Organització i duració

- Parelles.
- **4 hores**: 45 minuts de planificació, 90 d’instal·lació, 60 de verificació i 45 de documentació.

## Tasca 1. Trieu els entorns

Instal·leu els dos IDE fixats per a la UP: Visual Studio Code i IntelliJ IDEA. La fitxa ha d’explicar si IntelliJ IDEA s’utilitza amb les funcions bàsiques gratuïtes o amb les funcions avançades d’Ultimate —mitjançant subscripció o llicència educativa—, la llicència de cada producte i si l’ús concret és gratuït, educatiu o de pagament. No substituïu cap dels dos IDE.

## Tasca 3. Verifiqueu la instal·lació

Obriu un projecte Java amb Maven i, en VS Code, un programa Python de prova. Comproveu almenys:

1. l’IDE mostra la versió esperada;
2. detecta el llenguatge i el JDK o intèrpret correctes;
3. permet crear o obrir un projecte;
4. construeix un programa mínim;
5. executa el resultat i mostra l’eixida esperada en cada IDE.

No inclogueu claus de llicència, tokens ni dades personals en les captures.

## Lliurament

Entregueu `fitxa-instal·lacio.md` amb requisits, fonts oficials, versions, llicències, passos, proves, incidències i una conclusió de 150–200 paraules.

!!! tip "Abans d’entregar"
Una captura de la pantalla inicial no demostra que el JDK, Maven o Python funcionen. Incloeu ordres de versió i una construcció mínima en VS Code i IntelliJ IDEA.
