# UP2. Elements i eines del desenvolupament

## Presentació

En aquesta unitat estudiarem els elements que intervenen en el desenvolupament d’un programa: el sistema on s’executa, els llenguatges, els tipus de codi, les ferramentes, les fases, els equips i les metodologies de treball.

## Dades de la unitat

| Element | Referència |
| --- | --- |
| Duració de referència | **11 hores** |
| Resultat d’aprenentatge | **RA1** |
| Producte final | Anàlisi del recorregut d’un programa fins a la seua posada en funcionament |

## Què aprendràs

- Relacionar un programa amb el processador, la memòria, l’emmagatzematge i els perifèrics.
- Diferenciar codi font, objecte, intermedi i executable.
- Classificar llenguatges de programació segons diversos criteris.
- Identificar la funció de les eines principals del desenvolupament.
- Ordenar les fases d’un projecte i reconéixer els perfils d’un equip.
- Diferenciar enfocaments predictius, iteratius, incrementals i àgils.

## Resultat d’aprenentatge relacionat

**RA1.** Reconéixer els elements i les eines que intervenen en el desenvolupament d’un programa informàtic, analitzant les seues característiques i les fases en què actuen fins a arribar a la seua posada en funcionament.

## Continguts

Programa i sistema · llenguatges · tipus de codi · obtenció de l’executable · eines · fases · equips · metodologies àgils.
