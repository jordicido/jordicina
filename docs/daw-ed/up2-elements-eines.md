# UP2. Elements i eines del desenvolupament

## Presentació

En aquesta unitat estudiarem què ocorre des que apareix una necessitat fins que una aplicació es pot executar i mantindre. Relacionarem el programa amb el sistema informàtic, compararem llenguatges, seguirem la transformació del codi i coneixerem les ferramentes i metodologies d’un equip de desenvolupament.

El fil conductor serà una aplicació web de gestió de reserves. Ens ajudarà a entendre que desenvolupar programari no és només escriure codi: també cal analitzar requisits, triar una solució, construir-la, provar-la, desplegar-la i adaptar-la quan canvien les necessitats.

## Què aprendràs

- Relacionar un programa amb la CPU, la memòria, l’emmagatzematge, el sistema operatiu i els perifèrics.
- Diferenciar codi font, codi objecte, codi intermedi i codi executable.
- Explicar per què Java utilitza una JVM i comparar els models habituals de C, Python i JavaScript.
- Classificar llenguatges segons l’abstracció, els paradigmes, el tipatge i la manera d’executar-los.
- Reconéixer les fases que transformen una necessitat en una aplicació desplegada i mantinguda.
- Identificar la funció d’un IDE, un compilador, un gestor de dependències, Git, un debugger i CI/CD.
- Entendre quan i per què un equip utilitza enfocaments iteratius, Scrum o Kanban.

## Resultat d’aprenentatge i criteris

**RA1.** Reconeix els elements i les ferramentes que intervenen en el desenvolupament d’un programa informàtic, analitzant les seues característiques i les fases en què actuen fins a arribar a la seua posada en funcionament.

| Criteri | Què hauràs de poder explicar |
| --- | --- |
| **RA1.a** | Com es relaciona un programa amb la memòria, el processador i els perifèrics. |
| **RA1.b** | Quines fases transformen una necessitat en una aplicació mantinguda. |
| **RA1.c** | Quina diferència hi ha entre codi font, objecte i executable. |
| **RA1.d** | Per què existeix el codi intermedi i quin paper té una màquina virtual. |
| **RA1.e** | Com es poden classificar els llenguatges i en quins contextos s’utilitzen. |
| **RA1.f** | Quina funció té cada ferramenta dins del procés de desenvolupament. |
| **RA1.g** | Per què i quan s’utilitzen metodologies àgils de desenvolupament. |

## Seqüència de treball

Primer entendràs què passa quan s’executa un programa i com cooperen el sistema operatiu i el maquinari. Després compararàs llenguatges i seguiràs el camí del codi font fins a l’execució. A continuació estudiaràs les fases i les ferramentes del desenvolupament. Finalment connectaràs tot el recorregut amb Scrum, Kanban i altres enfocaments àgils.

## Abans de començar

No cal memoritzar totes les ordres ni totes les ferramentes. L’objectiu és poder explicar quin problema resol cada element i què ocorre realment quan un programa es construeix i s’executa. En una UP posterior aprofundirem en les proves i en altres ferramentes del cicle de desenvolupament.
