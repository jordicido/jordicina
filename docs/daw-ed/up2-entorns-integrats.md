# UP2. Entorns integrats de desenvolupament

## 1. Introducció
Instal·larem i valorarem entorns integrats per editar codi font i generar executables.

## 2. Què aprendràs
Configuraràs IDE, mòduls, extensions i actualitzacions, i compararàs entorns lliures i propietaris.

## 3. Resultat d’aprenentatge relacionat
**RA2.** Avaluar entorns integrats de desenvolupament, analitzant les seues característiques per a editar codi font i generar executables.

## 4. Continguts
- Instal·lació i funcions d’un entorn de desenvolupament.
- Mòduls, extensions, personalització i automatització.
- Actualitzacions i generació d’executables.
- Comparació d’entorns i ús de diversos llenguatges.
