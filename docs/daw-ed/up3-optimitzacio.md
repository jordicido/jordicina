# UP3. Optimització i qualitat del codi

## Presentació

En aquesta unitat aprendrem a millorar codi existent amb les ferramentes de l’entorn de desenvolupament. Analitzarem la llegibilitat, la complexitat, els avisos i el rendiment abans de decidir quines modificacions aporten una millora real.

## Dades de la unitat

| Element | Referència |
| --- | --- |
| Duració de referència | **16 hores** |
| Resultat d’aprenentatge | **RA4** |
| Pes de referència | **25 %** |
| Producte final | Informe de qualitat, refactorització i justificació de millores |

## Què aprendràs

- Detectar problemes de llegibilitat, duplicació i complexitat.
- Utilitzar analitzadors, formatadors i inspeccions de l’entorn.
- Refactoritzar sense modificar el comportament comprovat.
- Mesurar una millora amb criteris i evidències.
- Documentar decisions, límits i possibles regressions.
- Integrar Git i automatització bàsica en el flux de qualitat.

## Resultat d’aprenentatge relacionat

**RA4.** Optimitzar codi emprant les eines disponibles a l’entorn de desenvolupament.

## Itinerari

1. Qualitat interna, llegibilitat i complexitat.
2. Formatació, inspeccions i analitzadors.
3. Duplicació, funcions massa grans i noms poc clars.
4. Refactorització segura i revisió del diff.
5. Mesura abans/després i documentació.
6. Lliurament de l’informe i defensa de les decisions.

## Evidències
