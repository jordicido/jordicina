# UP3. Proves i verificació

## 1. Introducció
Dissenyarem proves i utilitzarem eines de depuració per verificar el funcionament dels programes.

## 2. Què aprendràs
Definiràs casos de prova, faràs proves unitàries i automàtiques i documentaràs incidències.

## 3. Resultat d’aprenentatge relacionat
**RA3.** Verificar el funcionament de programes, dissenyant i realitzant proves.

## 4. Continguts
- Tipus de proves i planificació.
- Casos de prova, cobertura, valors límit i classes d’equivalència.
- Punts de ruptura, seguiment i modificació en temps d’execució.
- Proves unitàries, automatització, incidències i dobles de prova.
