# UP4. Optimització i qualitat del codi

## 1. Introducció
Millorarem el codi amb refactorització, analitzadors, control de versions i integració contínua.

## 2. Què aprendràs
Aplicaràs patrons de refactorització, revisaràs qualitat, documentaràs classes i col·laboraràs amb repositoris remots.

## 3. Resultat d’aprenentatge relacionat
**RA4.** Optimitzar codi emprant les eines disponibles a l’entorn de desenvolupament.

## 4. Continguts
- Refactorització, patrons i proves associades.
- Analitzadors de codi i configuració.
- Control de versions integrat i repositoris remots.
- Documentació de classes i integració contínua.
