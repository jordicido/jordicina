# Activitat 4 – Registre d'incidències

| Camp | Informació |
| --- | --- |
| **Mòdul** | Entorns de Desenvolupament · 1r DAW |
| **Unitat** | Disseny i realització de proves |
| **Resultat d'aprenentatge** | **RA3. Verifica el funcionament de programes, dissenyant i realitzant proves.** |
| **Criteri d'avaluació** | **CA3.h. S'han documentat les incidències detectades.** |
| **Duració** | 1 sessió (60 minuts) |
| **Modalitat** | Individual |
| **Ferramentes** | Java, Visual Studio Code i una fitxa de registre d'incidències |
| **Lliurament** | Fitxa emplenada mitjançant la tasca d'Aules |

## Objectiu

En aquesta activitat assumiràs el paper d'una persona encarregada de la qualitat del programari (QA). Treballaràs amb una aplicació de consola en Java que gestiona notes acadèmiques. L'aplicació s'executa, però presenta **tres comportaments incorrectes**.

La teua tasca consistirà a detectar-los, reproduir-los i documentar-los perquè una altra persona puga entendre què ha passat i repetir la incidència. **No cal corregir el codi font.**

!!! info "Material i instruccions"
    Consulta la tasca d'**Aules** per a seguir l'enunciat complet i utilitzar el material de treball. La fitxa de registre d'incidències també es facilitarà allí.

## Tasques

1. Llig els requisits funcionals de l'aplicació i executa-la amb Visual Studio Code.
2. Fes proves amb diferents valors i observa'n els resultats.
3. Detecta **tres incidències diferenciades**.
4. Registra cada incidència en la fitxa amb:
   - identificador i títol;
   - requisit afectat i gravetat;
   - precondicions;
   - passos per a reproduir-la;
   - resultat esperat i resultat obtingut;
   - evidència.
5. Lliura a Aules la fitxa completada.

## Criteri d'avaluació

Es valorarà que les tres incidències estiguen diferenciades, siguen reproduïbles i estiguen documentades amb informació suficient perquè una altra persona puga entendre el problema i repetir la prova. Aquesta activitat treballa únicament el **CA3.h**.

## Lliurament

Consulta la tasca d'**Aules** per a entregar la fitxa emplenada. No cal publicar cap fitxer, projecte Java ni document addicional en aquesta web.
