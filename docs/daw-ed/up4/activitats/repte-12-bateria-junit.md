# Repte 12. Una bateria que protegeix el contracte

## Modalitat

Repte individual d’ampliació. Treballa sobre el projecte inicial proporcionat i no consultes cap solucionari.

## Enunciat

Una classe valida codis de reserva segons tres regles: tenen sis caràcters, comencen per dues lletres majúscules i acaben amb quatre dígits. La implementació inicial funciona per al cas feliç, però la bateria és massa curta per detectar errors de frontera.

Descarrega el [projecte Maven inicial](recursos/repte-12/pom.xml) i els fitxers Java del projecte. Afegeix una bateria parametritzada que faça visibles les dades de cada cas i cobrisca longitud, majúscules, dígits i valors just abans i després de cada frontera.

## Producte

- Tests JUnit amb noms o paràmetres informatius.
- Com a mínim huit casos justificats.
- Una execució verda amb `mvn test`.
- Una nota sobre quin defecte quedaria sense detectar si només proves el camí feliç.
