# UP5. Diagrames de classes

## 1. Introducció
Modelarem l’estructura d’aplicacions amb diagrames de classes i eines específiques.

## 2. Què aprendràs
Identificaràs classes, atributs, mètodes, relacions i visibilitat, i generaràs codi i diagrames per enginyeria inversa.

## 3. Resultat d’aprenentatge relacionat
**RA5.** Generar diagrames de classes valorant la seua importància en el desenvolupament d’aplicacions.

## 4. Continguts
- Programació orientada a objectes.
- Classes, objectes, atributs, mètodes i visibilitat.
- Associació, navegabilitat, multiplicitat, herència, composició, agregació i dependència.
- Notació UML, eines, generació automàtica de codi i enginyeria inversa.
