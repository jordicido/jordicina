# UP5. Diagrames de classes

## Presentació

En aquesta unitat modelarem l’estructura estàtica d’una aplicació amb diagrames de classes. Relacionarem classes, atributs, operacions i associacions amb una solució orientada a objectes implementable.

## Dades de la unitat

| Element | Referència |
| --- | --- |
| Duració de referència | **11 hores** |
| Resultat d’aprenentatge | **RA5** |
| Pes de referència | **15 %** |
| Producte final | Diagrama de classes justificat i correspondència amb codi |

## Què aprendràs

- Identificar classes i responsabilitats a partir d’un problema.
- Representar atributs, operacions, associacions, agregacions i composicions.
- Utilitzar visibilitat, generalització i dependències amb criteri.
- Evitar models amb responsabilitats duplicades o acoblaments innecessaris.
- Passar del diagrama a una estructura de codi i revisar-ne la coherència.

## Resultat d’aprenentatge relacionat

**RA5.** Generar diagrames de classes valorant la seua importància en el desenvolupament d’aplicacions i emprant ferramentes específiques.

## Itinerari

1. Classes, objectes i responsabilitats.
2. Atributs, operacions i visibilitat.
3. Associacions i multiplicitats.
4. Herència, interfícies i dependències.
5. Diagrama final, revisió i correspondència amb codi.
