# Guia de l’assignatura

## 1. Presentació del mòdul

En aquest mòdul compartit de SMX i DAW aprendrem a programar amb Python. Començarem per entendre l’estructura d’un programa i avançarem cap a la depuració, les classes, les llibreries i les estructures avançades de dades.

La distribució del mòdul és de **62 hores lectives** organitzades en sis unitats de programació. Cada UP està relacionada amb un resultat d’aprenentatge, unes hores de referència i un pes d’avaluació.

## 2. Què aprendrem

- Reconéixer l’estructura d’un programa i els elements del llenguatge Python.
- Escriure, executar i provar programes senzills.
- Utilitzar condicions, bucles i tècniques bàsiques de depuració.
- Desenvolupar programes organitzats en classes aplicant principis d’orientació a objectes.
- Llegir i escriure informació amb fitxers, mòduls i llibreries.
- Manipular informació amb llistes, tuples, diccionaris i conjunts.

## 3. Organització del curs

El mòdul s’organitza en sis unitats de programació. La seqüència és acumulativa: els conceptes de les primeres UP es reutilitzen i amplien en les següents.

## 5. Metodologia de treball

Treballarem amb explicacions breus, exemples executables, exercicis graduals i reptes de dificultat creixent. Cada solució haurà de funcionar, ser llegible i poder-se explicar. Els errors formen part del procés: els llegirem, els reproduirem i documentarem com s’han resolt.

## 6. Materials i programes necessaris

Cal disposar d’un ordinador amb Python 3, un editor o entorn de desenvolupament, una terminal i connexió a Internet per consultar la documentació. La instal·lació concreta de cada eina s’indicarà en la pràctica corresponent.

## 7. Funcionament de les classes

Consulta la unitat abans de cada sessió i conserva el codi de les activitats. Prova els programes amb més d’un cas, especialment amb entrades buides, valors límit o dades incorrectes.

## 8. Entrega de pràctiques

Cada lliurament ha d’incloure el codi, una explicació breu, exemples d’execució i les proves sol·licitades. El canal, el format i la data exactes quedaran indicats en cada activitat.

## 9. Normes bàsiques

- Escriu codi llegible i utilitza noms descriptius.
- No copies solucions sense entendre-les ni poder-les explicar.
- Prova el programa abans de donar una tasca per acabada.
- Documenta les fonts i les decisions tècniques.
- No publiques credencials ni dades sensibles en el codi.
- Conserva una còpia del treball fins al tancament de l’avaluació.
