# Preguntes freqüents

## On puc trobar els apunts?

En els materials de la unitat de programació corresponent i, quan així s’indique, en la plataforma del centre.

## Com he d’entregar un programa?

Segueix les instruccions de l’activitat i inclou el codi, els casos de prova, exemples d’execució i l’explicació sol·licitada.

## Quina versió de Python he d’utilitzar?

La versió s’indicarà en cada pràctica. Utilitza una versió compatible amb l’activitat i documenta qualsevol diferència del teu entorn.

## Què faig si el programa dona un error?

Llig el missatge, localitza la línia indicada, reprodueix l’error amb una entrada controlada i prova una correcció. No elimines l’error sense entendre’n la causa.

## Què passa si entregue una activitat fora de termini?

Consulta el professorat, perquè el format i les condicions dels lliuraments quedaran indicats en cada activitat.

## Com puc recuperar un resultat d’aprenentatge?

Es poden recuperar els criteris no superats en la convocatòria i el format que comunique el professorat. Consulta la pàgina d’[avaluació](avaluacio.md).

## Quines eines necessite instal·lar?

Python 3, un editor o entorn de desenvolupament i una terminal. Instal·la només les eines indicades en cada pràctica.

## On estan els enllaços de descàrrega?

En la pàgina de [recursos](recursos.md), quan s’hagen revisat i afegit les adreces oficials.
