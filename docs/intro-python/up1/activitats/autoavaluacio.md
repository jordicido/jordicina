# Autoavaluació de la UP1

Aquesta autoavaluació serveix per detectar què necessites repassar abans de lliurar els exercicis i defensar-los. Respon amb les teues paraules i relaciona les respostes amb el teu codi.

## Comprova els conceptes

1. Què és un programa informàtic?
2. Per què l’ordre de les instruccions és important?
3. Quina diferència hi ha entre Python i l’intèrpret de Python?
4. Quina funció té l’extensió de Python de VS Code?
5. Què és l’intèrpret seleccionat en un projecte?
6. Quina diferència hi ha entre `18` i `"18"`?
7. Quins tipus representen `18`, `3.5`, `"Python"` i `True`?
8. Què fa l’operador `=` en una assignació?
9. Què retorna sempre `input()`?
10. Per què cal utilitzar `int()` o `float()`?
11. Explica el recorregut d’una dada en el model entrada → variables/processament → eixida.
12. Per què és millor anomenar una variable `preu_unitari` que `p`?

## Comprova la pràctica

- [ ] Puc mostrar la versió de Python i explicar quin intèrpret utilitza VS Code.
- [ ] Puc crear i obrir la carpeta `python/up1`.
- [ ] Puc executar `hola.py` des de VS Code i des de la terminal.
- [ ] Puc explicar l’ordre d’execució d’un programa lineal.
- [ ] Puc reconéixer `int`, `float`, `str` i `bool`.
- [ ] Puc crear, consultar i modificar una variable.
- [ ] Puc explicar que `input()` retorna text.
- [ ] Puc convertir una entrada a enter o decimal.
- [ ] Puc explicar qualsevol dels meus dotze exercicis.
- [ ] Puc fer una modificació breu sense trencar el programa.

## Repte final

Obri l’exercici 12 i explica, en ordre, què passa des que l’usuari escriu el producte, el preu i la quantitat fins que apareix el total. Després canvia el nom de `preu` a `preu_unitari` i comprova que el programa continua funcionant.

Si no pots assenyalar cada pas en el codi, torna a [l’estructura del programa](../01-programa.md), [les variables](../04-variables.md) i [l’entrada de dades](../06-input.md).
