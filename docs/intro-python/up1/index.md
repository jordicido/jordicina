# UP1. Primers passos amb Python

## Resultat d’aprenentatge

**RA1.** Reconéixer l’estructura d’un programa informàtic, identificant i relacionant els elements propis del llenguatge de programació utilitzat.

## Criteris d’avaluació

- **RA1.a** Identificar els blocs que componen l’estructura d’un programa informàtic.
- **RA1.b** Crear projectes de desenvolupament d’aplicacions.
- **RA1.c** Utilitzar entorns integrats de desenvolupament.
- **RA1.d** Identificar els tipus de variables i la utilitat específica de cadascun.
- **RA1.e** Modificar el codi per crear i utilitzar variables.
- **RA1.f** Crear i utilitzar constants i literals.
- **RA1.g** Classificar, reconéixer i utilitzar els operadors en expressions.
- **RA1.h** Comprovar conversions de tipus explícites i implícites.
- **RA1.i** Introduir comentaris en el codi.

## Què aprendrem?

En aquesta unitat prepararàs un entorn funcional amb Python i Visual Studio Code. Escriuràs scripts lineals, observaràs com s’executen de dalt cap avall i practicaràs el recorregut d’una dada des de l’entrada fins a l’eixida.

L’objectiu no és memoritzar opcions de l’editor. És poder crear un projecte, executar un programa, reconéixer els seus elements i explicar què passa en cada línia. La teoria no inclou encara condicions, bucles, llistes ni funcions.

## Seqüència de treball

| Sessió | Teoria | Treball pràctic |
| ---: | --- | --- |
| **1** | Python, intèrpret i entorn de desenvolupament | Instal·lació de Python i Visual Studio Code. |
| **2** | VS Code, extensió, intèrpret i projecte | Finalitzar l’activitat 1 i completar l’exercici 0 de l’activitat 2. |
| **3** | Programa, instruccions, ordre d’execució i `print()` | Exercicis 1 i 2. |
| **4** | Variables, assignació, tipus bàsics i `type()` | Exercicis 3, 4 i 5. |
| **5** | `input()`, conversió de tipus i operacions | Exercicis 6, 7, 8 i 9. |

Les explicacions teòriques es limitaran a blocs curts, habitualment de 20–25 minuts com a màxim. La resta de la sessió es dedicarà a escriure, executar, observar i corregir codi.
