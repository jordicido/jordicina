# UP2. Programes senzills i orientació a objectes

## Presentació

En aquesta unitat escriurem programes senzills i aprendrem a comprovar que fan allò que esperem. Introduirem les idees d’objecte, classe, atribut i mètode com a base de l’organització del programari.

## Dades de la unitat

| Element | Referència |
| --- | --- |
| Duració de referència | **9 hores** |
| Resultat d’aprenentatge | **RA2** |
| Pes de referència | **20 %** |
| Producte final | Programa senzill amb proves i explicació de la solució |

## Què aprendràs

- Escriure programes curts a partir d’un enunciat.
- Executar-los i comprovar-los amb casos representatius.
- Separar dades i operacions amb funcions senzilles.
- Reconéixer objectes, classes, atributs i mètodes en exemples propers.

## Resultat d’aprenentatge relacionat

**RA2.** Escriure i provar programes senzills, reconeixent i aplicant els fonaments de la programació orientada a objectes.

## Itinerari

1. Del problema a l’algoritme.
2. Funcions senzilles i reutilització.
3. Casos de prova i resultats esperats.
4. Objectes i classes en Python.
