# UP3. Control i depuració

## Presentació

En aquesta unitat aprendrem a controlar el flux dels programes i a depurar-los. Treballarem decisions, repeticions, comptadors, acumuladors i validació d’entrades per resoldre problemes més complets.

## Dades de la unitat

| Element | Referència |
| --- | --- |
| Duració de referència | **20 hores** |
| Resultat d’aprenentatge | **RA3** |
| Pes de referència | **25 %** |
| Producte final | Programa amb estructures de control, proves i informe de depuració |

## Què aprendràs

- Utilitzar condicions simples, alternatives i condicions encadenades.
- Construir bucles amb comptadors, acumuladors i sentinelles.
- Validar dades d’entrada i gestionar casos límit.
- Localitzar, reproduir i corregir errors del programa.
- Explicar el recorregut del codi i justificar les proves realitzades.

## Resultat d’aprenentatge relacionat

**RA3.** Escriure i depurar codi, analitzant i utilitzant les estructures de control del llenguatge.

## Itinerari

1. Condicions i decisions.
2. Bucles i patrons de repetició.
3. Comptadors, acumuladors i recorreguts.
4. Validació i casos límit.
5. Errors, depuració i regressió.
