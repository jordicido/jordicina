# UP3. Estructures de control, excepcions i depuració en Python

## Resultat d’aprenentatge

**RA3.** Escriure i depurar codi utilitzant estructures de control.

## Criteris d’avaluació

- **RA3.a** S’ha escrit i provat codi que faça ús d’estructures de selecció.
- **RA3.b** S’han utilitzat estructures de repetició.
- **RA3.c** S’han reconegut les possibilitats de les sentències de salt.
- **RA3.d** S’ha escrit codi utilitzant control d’excepcions.
- **RA3.e** S’han creat programes executables utilitzant diferents estructures de control.
- **RA3.f** S’han provat i depurat els programes.
- **RA3.g** S’ha comentat i documentat el codi.
- **RA3.h** S’han creat excepcions.
- **RA3.i** S’han utilitzat assercions per a la detecció i correcció d’errors durant la fase de desenvolupament.

## Què aprendrem?

En aquesta unitat aprendràs a controlar el flux d’execució d’un programa Python i a revisar-lo de manera sistemàtica. Escriuràs condicions, construiràs bucles, validaràs entrades i tractaràs els errors perquè els programes siguen més segurs, llegibles i fàcils de mantenir.

L’objectiu no és memoritzar sentències aïllades. És saber triar l’estructura adequada, provar els casos importants, trobar la causa d’un error i deixar el codi prou documentat perquè una altra persona el puga entendre.

## Continguts

1. [Estructures de selecció](01-estructures-seleccio.md): decisions amb `if`, `elif`, `else` i `match`.
2. [Estructures de repetició](02-estructures-repeticio.md): `while`, `for`, comptadors, acumuladors i sentinelles.
3. [Sentències de salt](03-sentencies-salt.md): `break`, `continue`, `pass` i `else` en bucles.
4. [Control d’excepcions](04-control-excepcions.md): errors en temps d’execució i recuperació.
5. [Excepcions pròpies](05-excepcions-propies.md): errors expressius del domini del programa.
6. [Assercions](06-assercions.md): comprovacions internes durant el desenvolupament.
7. [Proves i depuració](07-proves-depuracio.md): casos de prova, `print()` i depurador de VS Code.
8. [Documentació i bones pràctiques](08-documentacio-bones-practiques.md): codi llegible, comentaris i mantenibilitat.

## Seqüència de treball

| Fase | Treball principal |
| --- | --- |
| 1 | Resoldre decisions amb estructures de selecció i comprovar totes les branques. |
| 2 | Construir bucles amb comptadors, acumuladors i condicions de finalització. |
| 3 | Controlar el flux amb sentències de salt i combinar estructures de control. |
| 4 | Validar entrades i tractar errors amb excepcions incorporades i pròpies. |
| 5 | Utilitzar assercions, dissenyar casos de prova i depurar programes. |
| 6 | Integrar les estructures en un programa executable i documentar-lo. |

Les explicacions teòriques es combinaran amb exemples curts i pràctica guiada. Cada bloc recupera els anteriors: les excepcions s’apliquen a la validació i als bucles, i les proves i la depuració serveixen per revisar el programa complet.
