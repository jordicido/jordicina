# UP6. Estructures avançades de dades

## Presentació

En aquesta unitat seleccionarem el tipus de dada més adequat per representar i manipular informació. Combinarem col·leccions, recorreguts i transformacions per construir un petit programa de gestió.

## Dades de la unitat

| Element | Referència |
| --- | --- |
| Duració de referència | **6 hores** |
| Resultat d’aprenentatge | **RA6** |
| Pes de referència | **10 %** |
| Producte final | Programa curt de gestió i consulta d’informació |

## Què aprendràs

- Utilitzar llistes, tuples, diccionaris i conjunts.
- Triar una estructura segons les operacions que cal realitzar.
- Afegir, eliminar, buscar i ordenar informació.
- Recórrer estructures i combinar-ne diverses.
- Provar que les dades es conserven i es transformen correctament.

## Resultat d’aprenentatge relacionat

**RA6.** Escriure programes que manipulen informació, seleccionant i utilitzant tipus avançats de dades.

## Itinerari

1. Llistes i seqüències.
2. Tuples i dades immutables.
3. Diccionaris i associacions clau-valor.
4. Conjunts i eliminació de duplicats.
5. Selecció de l’estructura i programa final.
