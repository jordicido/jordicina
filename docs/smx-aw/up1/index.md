# UP1. Aplicacions web de correu i calendari

En aquesta unitat aprendrem a utilitzar, instal·lar i configurar aplicacions web orientades a la **comunicació i la productivitat**.

Ens centrarem principalment en dos tipus d'aplicacions:

- aplicacions de **correu electrònic web**;
- aplicacions de **calendari i agenda web**.

L'objectiu no és configurar des de zero un servidor de correu electrònic, sinó entendre com les aplicacions web es connecten als serveis existents i com podem posar-les a disposició dels usuaris.

## Què aprendrem?

En acabar la unitat serem capaços de:

- diferenciar una aplicació web d'una aplicació d'escriptori;
- identificar els components que intervenen en un sistema de correu electrònic;
- entendre la funció dels protocols **SMTP** i **IMAP**;
- instal·lar una aplicació de correu web;
- configurar-la perquè es connecte a un servidor de correu;
- gestionar la configuració dels usuaris;
- comprovar l'enviament i la recepció de missatges;
- instal·lar una aplicació de calendari web;
- utilitzar cites, recordatoris, calendaris compartits i altres funcionalitats de productivitat.

Durant la unitat treballarem amb aplicacions com:

- **Roundcube**, com a client de correu electrònic web;
