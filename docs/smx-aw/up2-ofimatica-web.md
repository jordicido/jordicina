# UP2. Aplicacions d’ofimàtica web

En aquesta unitat aprendràs a entendre, desplegar i administrar una solució d’ofimàtica web. El focus no és aprendre una aplicació concreta de memòria, sinó saber prendre decisions tècniques i treballar-hi de manera segura.

!!! info "Situació professional"
    Treballes com a tècnic o tècnica informàtica en una empresa que utilitza Microsoft 365. A més de donar suport als usuaris, has de saber utilitzar les seues eines, organitzar la informació, compartir-la correctament, treballar de manera col·laborativa i aplicar permisos segurs. Durant aquesta unitat treballaràs amb el mateix entorn Microsoft 365 que tens disponible amb el teu compte educatiu.

## Resultat d’aprenentatge

**RA4. Instal·la aplicacions d’ofimàtica web, descrivint les seues característiques i entorns d’ús.**

| Criteri | Descripció |
|---|---|
| **RA4.a** | S’ha establit la utilitat de les aplicacions d’ofimàtica web. |
| **RA4.b** | S’han descrit diferents aplicacions d’ofimàtica web (processador de textos, full de càlcul, entre altres). |
| **RA4.c** | S’han instal·lat aplicacions d’ofimàtica web. |
| **RA4.d** | S’han gestionat els comptes d’usuari. |
| **RA4.e** | S’han aplicat criteris de seguretat en l’accés dels usuaris. |
| **RA4.f** | S’han reconegut les prestacions específiques de cadascuna de les aplicacions instal·lades. |
| **RA4.g** | S’han utilitzat les aplicacions de manera col·laborativa. |
