# UP2. Aplicacions d’ofimàtica web

## 1. Introducció
Treballarem amb aplicacions d’ofimàtica web i els seus entorns d’ús col·laboratiu.

## 2. Què aprendràs
Instal·laràs aplicacions, gestionaràs comptes, aplicaràs criteris de seguretat i utilitzaràs les seues funcions col·laboratives.

## 3. Resultat d’aprenentatge relacionat
**RA4.** Instal·lar aplicacions d’ofimàtica web, descrivint les seues característiques i entorns d’ús.

## 4. Continguts

- Utilitat i tipus d’aplicacions d’ofimàtica web.
- Instal·lació i ús de les aplicacions.
- Gestió de comptes d’usuari.
- Seguretat en l’accés.
- Prestacions específiques i treball col·laboratiu.
