# UP2. Aplicacions d’ofimàtica web

En aquesta unitat aprendràs a entendre, desplegar i administrar una solució d’ofimàtica web. El focus no és aprendre una aplicació concreta de memòria, sinó saber prendre decisions tècniques i treballar-hi de manera segura.

!!! info "Situació professional"
    Una xicoteta empresa vol deixar de passar documents per correu electrònic. Necessita un espai on l’equip puga crear documents, fulls de càlcul i presentacions, compartir-los amb permisos diferents i recuperar versions anteriors. Com a tècnic o tècnica de suport hauràs de comparar solucions, desplegar-ne una en una màquina virtual i preparar els comptes de l’equip.

## Resultat d’aprenentatge

**RA4. Instal·la aplicacions d’ofimàtica web, descrivint les seues característiques i entorns d’ús.**

| Criteri | Descripció |
|---|---|
| **RA4.a** | S’ha establit la utilitat de les aplicacions d’ofimàtica web. |
| **RA4.b** | S’han descrit diferents aplicacions d’ofimàtica web (processador de textos, full de càlcul, entre altres). |
| **RA4.c** | S’han instal·lat aplicacions d’ofimàtica web. |
| **RA4.d** | S’han gestionat els comptes d’usuari. |
| **RA4.e** | S’han aplicat criteris de seguretat en l’accés dels usuaris. |
| **RA4.f** | S’han reconegut les prestacions específiques de cadascuna de les aplicacions instal·lades. |
| **RA4.g** | S’han utilitzat les aplicacions de manera col·laborativa. |

## Evidències i temporalització

Les evidències són captures o registres de les comprovacions, fitxers creats i una explicació breu de les decisions preses. No cal redactar un informe llarg: l’objectiu és demostrar que la solució funciona i que s’ha configurat amb criteri.

| Sessió | Treball | Evidència principal |
|---:|---|---|
| 1 | Fonaments i Activitat 1 | Taula comparativa i decisió justificada |
| 2–3 | Instal·lació i Activitat 2 | Servei accessible, ordres i incidències resoltes |
| 4 | Usuaris, permisos i seguretat | Matriu de permisos i correcció d’un risc |
| 5–6 | Activitat 3 | Espai compartit i proves d’accés |
| 7 | Activitat 3 | Comentaris, versions i configuració segura |
| 8 | Repàs i tancament | Lliurament individual revisat |

!!! warning "Entorn de pràctiques"
    Les instal·lacions es faran en una màquina virtual o en un entorn proporcionat pel centre. No publiques el servei en Internet ni utilitzes dades personals reals.
