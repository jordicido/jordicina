# Activitat 1. Dissenyem una oficina al núvol

**Duració:** 3–4 hores · **Modalitat:** individual, amb evidències individuals

## Objectiu

Triar les aplicacions de Microsoft 365 adequades per a cada necessitat i utilitzar Word, Excel, PowerPoint i OneDrive per a organitzar un projecte professional complet des del navegador.

## Situació

Treballes com a tècnic o tècnica informàtica en una xicoteta empresa que prepara una jornada. Has d’analitzar què necessita l’equip, decidir quina aplicació utilitzar en cada cas i construir una oficina al núvol ordenada i funcional.

El resultat serà un únic projecte: el document de Word descriurà la jornada, el full d’Excel n’arreplegarà el pressupost i la presentació de PowerPoint comunicarà la proposta.

## Fase 1. Decidir les eines

1. Inicia sessió amb el compte educatiu i obri el llançador d’aplicacions de Microsoft 365.
2. Localitza **Word**, **Excel**, **PowerPoint** i **OneDrive**.
3. Completa aquesta taula abans de crear els fitxers:

| Necessitat | Aplicació principal | Per què és adequada? | Precaució |
|---|---|---|---|
| Redactar el programa de la jornada | | | |
| Calcular el pressupost i crear un gràfic | | | |
| Presentar la proposta a la direcció | | | |
| Organitzar i recuperar els fitxers del projecte | | | |
| Compartir un document sense permetre que el modifiquen | | | |

!!! tip "Punt de control 1"
    Abans de continuar, has de poder justificar cada elecció relacionant la necessitat amb una prestació concreta de l’aplicació.

## Fase 2. Preparar l’espai de treball

1. Crea en OneDrive l’estructura següent:

   ```text
   Projecte_Jornada/
   ├── Documentació/
   ├── Pressupostos/
   └── Presentacions/
   ```

2. Decideix noms clars per als tres fitxers que crearàs.
3. Comprova que treballes dins de l’espai educatiu autoritzat i que no utilitzaràs dades personals reals.

!!! tip "Punt de control 2"
    Les tres carpetes han d’existir abans de crear els documents. Cada fitxer s’ha de guardar directament en la carpeta corresponent.

## Fase 3. Crear els productes

### 3.1. Programa en Word Online

Crea dins de `Documentació` un document professional amb:

- títol i subtítols amb estils;
- índex automàtic;
- una taula amb el programa de la jornada;
- una imatge amb text alternatiu;
- almenys dos enllaços;
- capçalera, peu de pàgina i una conclusió.

### 3.2. Pressupost en Excel Online

Crea dins de `Pressupostos` un pressupost amb:

- almenys sis conceptes, quantitat i preu unitari;
- fórmules de suma i percentatge;
- format de taula i filtres;
- una cel·la que indique si el cost supera el pressupost màxim;
- un gràfic amb el pes de les principals despeses.

### 3.3. Proposta en PowerPoint Online

Crea dins de `Presentacions` una presentació de cinc o sis diapositives amb:

- objectiu i públic de la jornada;
- programa resumit a partir del document de Word;
- pressupost amb el gràfic d’Excel;
- una diapositiva de conclusions;
- coherència visual, poc text i fonts llegibles.

!!! tip "Punt de control 3"
    Els tres productes han de parlar de la mateixa jornada. Les dades del pressupost i el gràfic de la presentació han de coincidir amb el full d’Excel.

## Fase 4. Comprovar el funcionament

1. Revisa que els tres fitxers tinguen noms clars i estiguen en la carpeta correcta.
2. Modifica un dels fitxers, espera que es guarde i localitza una versió anterior en l’historial. No cal restaurar-la sobre el fitxer final.
3. Tanca una aplicació, torna a obrir el fitxer des d’OneDrive i comprova que els canvis s’han guardat.
4. Si el navegador i el compte ho permeten, instal·la una de les aplicacions web com a PWA i verifica que mostra els mateixos fitxers. Si l’opció no està disponible, documenta la limitació i crea un accés ràpid segur, com un favorit.
5. Explica com compartiries el projecte amb una persona que només l’ha de consultar.

Perquè el professorat puga corregir el projecte, comparteix la carpeta `Projecte_Jornada` amb **j.cidonchanavarret@edu.gva.es** amb permís de **visualització**. No utilitzes l’opció **Qualsevol persona amb l’enllaç** ni dones permisos d’edició.

## Comprovació final

- [ ] He justificat l’aplicació triada per a cada necessitat.
- [ ] L’estructura de OneDrive està completa i ordenada.
- [ ] El document de Word conté tots els elements demanats.
- [ ] Les fórmules d’Excel calculen correctament i el gràfic correspon a les dades.
- [ ] La presentació reutilitza informació del document i del pressupost.
- [ ] He localitzat una versió anterior d’un fitxer.
- [ ] He comprovat l’accés web o la PWA i he documentat qualsevol limitació.
- [ ] No he compartit enllaços públics ni dades personals reals.

## Lliurament

Comparteix la carpeta `Projecte_Jornada` amb **j.cidonchanavarret@edu.gva.es** amb permís de visualització i lliura també l’enllaç a la carpeta i una fitxa d’evidències d’una o dues pàgines amb:

- la taula de decisions de la fase 1;
- una captura de l’estructura d’OneDrive;
- una captura de cada aplicació en ús;
- l’explicació de dues fórmules d’Excel i del gràfic;
- la prova que has localitzat l’historial de versions;
- la comprovació de la PWA o l’explicació de la limitació trobada;
- una precaució per a protegir els fitxers en un entorn real.

No cal repetir en la fitxa el contingut complet dels tres fitxers: han d’estar disponibles dins de la carpeta lliurada.

## Errors que has de saber diagnosticar

- **Fitxer difícil de trobar:** revisa la carpeta i el nom abans de crear una còpia.
- **Fórmula incorrecta:** comprova les cel·les d’origen i el separador utilitzat pel compte.
- **Gràfic desactualitzat:** actualitza el rang de dades i verifica la llegenda.
- **Format inconsistent:** aplica estils i un tema abans de retocar cada element manualment.
- **Canvis no guardats:** torna a obrir el fitxer des d’OneDrive i comprova la sessió i la ubicació.
- **PWA no disponible:** documenta el navegador, el compte i l’accés web alternatiu.

!!! warning "Àmbit segur"
    Utilitza només l’espai educatiu autoritzat. No compartisques la carpeta amb enllaços públics ni uses dades personals o informació real de clients.
