# Activitat 2. La meua oficina al núvol

**Duració:** 2–3 hores · **Modalitat:** individual, amb evidències individuals

## Objectiu

Dominar les aplicacions web principals de Microsoft 365 i organitzar un petit projecte professional en OneDrive.

## Situació

Una xicoteta empresa prepara una jornada i necessita crear, ordenar i presentar la informació del projecte. Com a tècnic o tècnica de suport, has de preparar una estructura clara i demostrar que saps utilitzar Word, Excel i PowerPoint des del navegador.

## Tasques

1. Crea en OneDrive l’estructura següent:

   ```text
   Projecte_Jornada/
   ├── Documentació/
   ├── Pressupostos/
   └── Presentacions/
   ```

2. En **Word Online**, crea dins de `Documentació` un document professional amb:

   - títol i subtítols amb estils;
   - índex automàtic;
   - una taula amb el programa de la jornada;
   - una imatge amb text alternatiu;
   - almenys dos enllaços;
   - capçalera, peu de pàgina i una conclusió.

3. En **Excel Online**, crea dins de `Pressupostos` un pressupost amb:

   - almenys sis conceptes, quantitat i preu unitari;
   - fórmules de suma i percentatge;
   - format de taula i filtres;
   - una cel·la que indique si el cost supera el pressupost màxim;
   - un gràfic amb el pes de les principals despeses.

4. En **PowerPoint Online**, crea dins de `Presentacions` una presentació de cinc o sis diapositives amb:

   - objectiu i públic de la jornada;
   - programa resumit;
   - pressupost amb el gràfic d’Excel;
   - una diapositiva de conclusions;
   - coherència visual, poc text i fonts llegibles.

5. Revisa que els tres fitxers tinguen noms clars i que estiguen en la carpeta correcta.
6. Si el navegador i el compte ho permeten, instal·la Word, Excel i PowerPoint web com a aplicacions (PWA). Si l’opció no està disponible, explica-ho i documenta com accediries ràpidament a les aplicacions des del navegador.

## Comprovacions

| Comprovació | Resultat esperat |
|---|---|
| Estructura d’OneDrive | Les tres carpetes existeixen i estan ordenades |
| Document de Word | Té estils, índex, taula, imatge i enllaços |
| Full d’Excel | Les fórmules calculen i el gràfic es correspon amb les dades |
| Presentació | Inclou el gràfic i manté una línia visual coherent |
| Historial de versions | Es pot identificar una versió anterior de, com a mínim, un fitxer |
| Aplicacions web | S’hi accedeix des del navegador o com a PWA, si és possible |

## Lliurament

Un document breu amb:

- l’enllaç o una captura de l’estructura d’OneDrive;
- una captura de cada aplicació en ús;
- una explicació de dues fórmules d’Excel i del gràfic;
- la relació entre el document, el pressupost i la presentació;
- la comprovació de la PWA o l’explicació de la limitació trobada;
- una breu reflexió sobre com protegiries aquests fitxers en un entorn real.

## Evidències necessàries

- L’estructura de carpetes.
- El document de Word amb els elements demanats.
- El full de càlcul amb fórmules, filtre i gràfic.
- La presentació amb el gràfic integrat.
- L’accés com a aplicació web o PWA, si està disponible.

!!! warning "Àmbit segur"
    Utilitza només l’espai educatiu autoritzat. No compartisques la carpeta amb enllaços públics ni uses dades personals o informació real de clients.

## Errors que has de saber diagnosticar

- **Fitxer difícil de trobar:** revisa la carpeta i el nom abans de crear una còpia.
- **Fórmula incorrecta:** comprova les cel·les d’origen i el separador utilitzat pel compte.
- **Gràfic desactualitzat:** actualitza el rang de dades i verifica la llegenda.
- **Format inconsistent:** aplica estils i un tema abans de retocar cada element manualment.
- **PWA no disponible:** documenta el navegador, el compte i l’accés web alternatiu.

## Criteris d’avaluació treballats

- RA4.c: instal·lar o configurar l’accés a aplicacions d’ofimàtica web, inclosa la possibilitat d’utilitzar-les com a PWA.
- RA4.f: comprovar les prestacions i l’entorn d’ús del servei instal·lat.
