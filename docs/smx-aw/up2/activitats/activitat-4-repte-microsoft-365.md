# Activitat 4. Repte Microsoft 365

**Duració:** 1,5–2 hores · **Modalitat:** grups de tres, amb resolució i evidències individuals

## Objectiu

Resoldre un cas professional que combine formularis, dades, documents, permisos i col·laboració, i justificar cada decisió tècnica.

## Situació

La vostra empresa organitza una jornada de portes obertes. Necessita recollir inscripcions, analitzar les respostes i preparar una comunicació per a l’equip. A més, el responsable us avisa que s’han detectat permisos massa amplis en una carpeta compartida.

Heu de construir un flux complet:

```text
Forms → respostes → Excel → gràfic → Word o PowerPoint
```

## Tasques

### 1. Crear el formulari

1. Crea un formulari de Microsoft Forms amb preguntes de resposta curta, opció única i selecció múltiple.
2. Inclou, com a mínim, nom o àlies, torn preferit, nombre d’acompanyants, interessos i una pregunta de confirmació.
3. Comparteix-lo només dins de l’entorn autoritzat o amb l’enllaç que indique el professorat.
4. Respon el formulari amb les persones del grup fins a obtindre almenys deu respostes fictícies.

### 2. Analitzar les respostes

1. Obri les respostes en Excel.
2. Calcula el nombre d’inscripcions per torn i el percentatge de cada opció.
3. Aplica almenys un filtre i crea un gràfic que ajude a prendre una decisió.
4. Escriu dues conclusions basades en les dades, sense inventar informació que no aparega en el full.

### 3. Preparar el resultat

Tria una de les dues opcions:

- **Word:** redacta un informe breu amb les conclusions, el gràfic i tres recomanacions organitzatives.
- **PowerPoint:** crea una presentació de quatre diapositives amb el problema, les dades, el gràfic i la proposta d’organització.

Comparteix el resultat amb el responsable del projecte amb permís de visualització i amb una persona revisora amb permís de comentari.

### 4. Resoldre incidències

El professorat assignarà, o el grup simularà, com a mínim dues d’aquestes incidències:

- un document compartit amb permís d’edició que hauria de ser només de lectura;
- una persona que ja no ha de tindre accés a una carpeta;
- una versió recent del document que conté un error i cal recuperar-ne una d’anterior;
- un comentari pendent que cal respondre i resoldre;
- un formulari que rep respostes que no corresponen a la pregunta prevista.

Per a cada incidència, documenta el símptoma, la causa probable, l’acció aplicada i la comprovació final.

## Lliurament

Un informe de 2–3 pàgines o la plantilla indicada pel professorat amb:

- enllaç o captura del formulari;
- taula de resultats i gràfic;
- informe de Word o presentació de PowerPoint;
- permisos aplicats als fitxers;
- dues incidències resoltes amb les seues proves;
- conclusió sobre com protegiries el flux en un entorn real.

## Evidències necessàries

- Captura del formulari sense dades personals reals.
- Captura de l’anàlisi en Excel amb fórmules, filtre i gràfic.
- Prova del permís de visualització i del permís de comentari.
- Historial de versions o registre de la incidència resolta.
- Explicació individual de les decisions preses.

!!! warning "Protecció de les evidències"
    Utilitza dades fictícies. Tapa adreces de correu, identificadors, enllaços amb tokens i qualsevol informació personal abans de lliurar captures.

## Criteris d’avaluació treballats

- RA4.e: aplicar permisos segurs i corregir configuracions inadequades.
- RA4.f: utilitzar prestacions específiques de Forms, Excel, Word i PowerPoint.
- RA4.g: treballar de manera col·laborativa i documentar incidències.
