# UP3. Gestió d’arxius web

**Mòdul:** Aplicacions Web — 2n SMX  
**Resultat d’aprenentatge:** RA3. Instal·la servicis de gestió d’arxius web, identificant les seues aplicacions i verificant la seua integritat.

## Criteris d’avaluació

| Criteri | Descripció |
|---|---|
| **RA3.a** | Establir la utilitat d’un servei de gestió d’arxius web. |
| **RA3.b** | Descriure diferents aplicacions de gestió d’arxius web. |
| **RA3.c** | Instal·lar i adaptar una ferramenta de gestió d’arxius web. |
| **RA3.d** | Crear i classificar comptes d’usuari en funció dels seus permisos. |
| **RA3.e** | Gestionar arxius i directoris. |
| **RA3.f** | Utilitzar arxius d’informació addicional. |
| **RA3.g** | Aplicar criteris d’indexació sobre els arxius i directoris. |
| **RA3.h** | Comprovar la seguretat del gestor d’arxius. |

!!! info "Fil conductor"
    Al llarg de la unitat utilitzarem **Nextcloud** per aplicar els conceptes sobre un servei real. L’objectiu no és només aprendre a utilitzar-lo, sinó entendre com funciona i com s’administra un servei web de gestió d’arxius.

!!! warning "Entorn de pràctiques"
    Utilitza dades fictícies, comptes de laboratori i una xarxa autoritzada. No publiques informació personal ni exposes el servei a Internet sense la indicació del professorat.
