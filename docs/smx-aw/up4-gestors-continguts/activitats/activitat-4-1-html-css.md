# Activitat 4.1 — La meua primera pàgina web amb HTML i CSS

**Mòdul:** Aplicacions Web · 2n d'SMX  
**Unitat:** UP4. Gestors de continguts web  
**Modalitat:** Individual  
**Caràcter:** Activitat preparatòria i formativa per al projecte de WordPress.

## Context

**ByteAcademy** és una acadèmia fictícia que imparteix cursos d'informàtica. Abans de construir la seua web amb WordPress, l'empresa vol un prototip de la portada per valorar-ne l'estructura i l'aparença.

La teua missió és crear una **pàgina web estàtica** sense utilitzar WordPress ni un constructor visual. Hauràs d'escriure el HTML i el CSS amb VS Code i comprovar el resultat en un navegador.

## Què has de fer?

### Part 1. Estructura HTML

1. Crea una carpeta de projecte amb `index.html`, `css/estils.css` i, si cal, `img/`.
2. Defineix l'estructura completa del document HTML.
3. Afig una capçalera amb el nom **ByteAcademy** i un menú d'enllaços interns.
4. Crea una secció de presentació amb un títol i un text introductori.
5. Crea una secció «Cursos» amb **almenys tres targetes** de cursos diferents.
6. Incorpora almenys una imatge amb un text alternatiu adequat.
7. Afig una secció de contacte amb informació fictícia i un peu de pàgina.
8. Utilitza etiquetes semàntiques (`header`, `nav`, `main`, `section`, `article`, `footer`).

### Part 2. Disseny amb CSS

1. Enllaça correctament el fitxer CSS extern.
2. Defineix una paleta coherent de colors i una tipografia llegible.
3. Personalitza la capçalera, el menú, els títols i les targetes de cursos.
4. Aplica `margin`, `padding`, `border` i `border-radius` on corresponga.
5. Utilitza **Flexbox** per distribuir les targetes.
6. Incorpora almenys una regla `@media` per millorar l'aparença en pantalles estretes.
7. Comprova el contrast i que el text continua sent llegible.

!!! tip "Treball progressiu"
    Primer aconsegueix que el HTML estiga ben estructurat i que els enllaços funcionen. Després incorpora CSS. Si intentes resoldre estructura i estil a la vegada, serà més difícil identificar els errors.

## Comprovacions obligatòries

- [ ] La portada s'obri correctament.
- [ ] Les tres targetes mostren títol i descripció.
- [ ] Els enllaços interns del menú funcionen.
- [ ] La imatge es carrega i té `alt` adequat.
- [ ] Les targetes utilitzen Flexbox.
- [ ] El web es pot consultar en una pantalla estreta sense perdre funcionalitat essencial.

## Validacions amb el professor

**Control 1 — HTML.** Mostra la pàgina abans d'acabar els estils. El professor comprovarà estructura, enllaços, imatges i ús d'etiquetes semàntiques.

**Control 2 — CSS.** Mostra el disseny final en format ordinador i mòbil, i explica una regla CSS de les que has escrit.

## Lliurament

Comprimeix la carpeta amb `index.html`, `css/estils.css` i les imatges necessàries en un arxiu ZIP i entrega'l a Aules. El resultat ha de funcionar sense connexions a recursos locals que només existisquen en el teu ordinador.

Afig un document breu `README.md` amb:

1. Els noms dels fitxers principals.
2. Una explicació de què has utilitzat per distribuir les targetes.
3. Una dificultat trobada i com l'has resolta.
4. Una captura de la pàgina en format mòbil.

## Per a què servirà després?

Conserva el projecte: en l'A4.2 recuperaràs la idea de les **targetes de cursos** i una part del CSS per personalitzar WordPress.
