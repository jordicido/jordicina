# UP5. Aplicacions web d’escriptori

## 1. Introducció
Configurarem aplicacions web d’escriptori relacionades amb el correu i el calendari.

## 2. Què aprendràs
Identificaràs aplicacions, instal·laràs l’accés web al correu, integraràs un servidor i gestionaràs comptes i calendaris.

## 3. Resultat d’aprenentatge relacionat
**RA5.** Instal·lar aplicacions web d’escriptori, descrivint les seues característiques i entorns d’ús.

## 4. Continguts

- Aplicacions web d’escriptori.
- Aplicacions de correu i calendari web.
- Instal·lació i integració amb un servidor de correu.
- Gestió de comptes i verificació de l’accés.
- Cites, tasques i altres prestacions.
