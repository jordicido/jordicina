# UP1. Mesures de seguretat passiva

## Presentació

En aquesta unitat aprendràs a protegir una xicoteta organització abans que una incidència es convertisca en una pèrdua de dades o en una aturada del servei. El fil conductor serà aquesta pregunta professional:

> **Com protegiríem físicament i controlaríem l’accés als sistemes informàtics d’una microempresa?**

La unitat combina conceptes, observació de l’entorn, documentació tècnica i presa de decisions. El resultat no serà una col·lecció d’exercicis aïllats, sinó un **pla bàsic de seguretat passiva** justificat.

## Dades de la unitat

| Element | Referència |
| --- | --- |
| Duració de referència | **14 hores** |
| Resultat d’aprenentatge | **RA1** |
| Producte final | Pla bàsic de seguretat passiva d’una microempresa |
| Forma de treball | Individual, parelles i equips de tres o quatre |

## Què aprendràs

- Valorar la informació i els sistemes com a actius que cal protegir.
- Distingir seguretat física, seguretat lògica, mesures actives i mesures passives.
- Detectar riscos derivats de la ubicació, l’ambient, l’electricitat, l’aigua, el foc o l’accés físic.
- Proposar proteccions per a equips, servidors, xarxa, suports i instal·lacions.
- Seleccionar i comprovar l’aplicació d’un SAI sense confondre potència, càrrega i autonomia.
- Dissenyar una política d’accés amb rols, permisos i principi de mínim privilegi.
- Justificar una política de contrasenyes i valorar quan té sentit la biometria.
- Comunicar les decisions en un informe tècnic breu i defensable.

## Resultat d’aprenentatge i criteris

**RA1.** Aplicar mesures de seguretat passiva en sistemes informàtics, descriure les característiques dels entorns i relacionar-les amb les seues necessitats.

| Criteri | Què hauràs de demostrar |
| --- | --- |
| **RA1.a** | Explicar per què cal mantindre segura la informació. |
| **RA1.b** | Diferenciar seguretat física i lògica i relacionar-les. |
| **RA1.c** | Definir una ubicació i unes condicions ambientals adequades. |
| **RA1.d** | Identificar la necessitat de protegir físicament els sistemes. |
| **RA1.e** | Verificar el funcionament d’un sistema d’alimentació ininterrompuda. |
| **RA1.f** | Seleccionar on i per a què s’ha d’aplicar un SAI. |
| **RA1.g** | Esquematitzar una política basada en llistes de control d’accés. |
| **RA1.h** | Valorar la importància d’una política de contrasenyes. |
| **RA1.i** | Valorar els avantatges i les limitacions dels sistemes biomètrics. |

## Abans de començar

No manipules quadres elèctrics, bateries, extintors, sistemes de videovigilància ni equipament de xarxa sense autorització. En l’auditoria no fotografies persones, pantalles amb dades personals ni credencials. Quan una comprovació no siga segura, descriu-la i deixa que la realitze el professorat.
