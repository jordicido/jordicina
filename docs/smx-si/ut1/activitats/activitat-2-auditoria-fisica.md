# Activitat 2. Auditoria física de l’aula

## Finalitat

Inspeccionareu un espai real autoritzat i convertireu les observacions en un informe tècnic amb propostes proporcionades.

Treballareu principalment els criteris **RA1.c** i **RA1.d**.

## Organització i duració

- Equips de tres o quatre.
- **4 hores**: 90 minuts d’inspecció, 90 de tractament de dades i 60 de redacció i posada en comú.

## Seguretat i límits

No obriu quadres elèctrics, no desconnecteu equips, no manipuleu SAI ni extintors i no entreu en espais no autoritzats. No feu fotografies de persones, pantalles, documents, claus o etiquetes que revelen informació sensible. Si no podeu comprovar un punt, marqueu-lo com a **no verificat**.

## Tasca 1. Checklist d’inspecció

Marqueu **Sí**, **No**, **No aplicable** o **No verificat** i afegiu evidència observable.

| Àmbit | Comprovació | Estat | Evidència o observació |
| --- | --- | --- | --- |
| Accés | La porta es pot tancar i controlar? |  |  |
| Accés | Les visites tenen un procediment? |  |  |
| Ubicació | Els equips crítics estan fora de zones de pas? |  |  |
| Ubicació | Hi ha finestres o canonades pròximes? |  |  |
| Ambient | La ventilació és suficient i no està bloquejada? |  |  |
| Ambient | S’observa pols o obstrucció dels ventiladors? |  |  |
| Electricitat | Les regletes i cables estan ordenats? |  |  |
| Electricitat | Hi ha endolls o adaptadors sobrecarregats? |  |  |
| Aigua i foc | Hi ha detecció o senyalització adequada? |  |  |
| Xarxa | Router, switch i rack tenen accés controlat? |  |  |
| Inventari | Els equips tenen identificador i responsable? |  |  |
| Ergonomia | El cablejat permet circular i evacuar? |  |  |

Afegiu quatre comprovacions pròpies adaptades a l’espai.

## Tasca 2. Registre d’incidències

Convertiu les respostes negatives o no verificades en incidències prioritzables:

| ID | Observació | Actiu afectat | Risc | Prioritat | Mesura | Cost | Responsable |
| --- | --- | --- | --- | --- | --- | --- | --- |
| I-01 | Cable pel corredor | Persones i xarxa | Caiguda o desconnexió | Alta | Canaleta i etiquetatge | Baix | Manteniment |

La prioritat ha de considerar impacte i probabilitat. El cost només és orientatiu: **baix**, **mitjà** o **alt**.

## Tasca 3. Informe professional

Redacteu un informe de quatre pàgines com a màxim:

1. descripció de l’espai i abast de l’auditoria;
2. metodologia i limitacions;
3. checklist resumida;
4. incidències ordenades per prioritat;
5. plànol senzill amb ubicació recomanada dels equips;
6. pla de millora amb responsable i termini orientatiu;
7. conclusió.

## Lliurament i defensa

Entregueu `informe-auditoria.md` i, si l’heu utilitzat, un plànol en PDF o imatge. Cada equip disposarà de cinc minuts per explicar la incidència més urgent i defensar una millora de cost baix.

!!! tip "Criteri de qualitat"
    Una observació com «la sala està malament» no és una evidència. Escriviu què heu vist, quin risc genera i quina actuació el redueix.
