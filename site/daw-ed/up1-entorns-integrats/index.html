    UP1. Entorns integrats de desenvolupament

    Presentació

    En aquesta unitat instal·larem, configurarem i compararem dos entorns integrats de desenvolupament (IDE): Visual Studio Code i IntelliJ IDEA. El fil conductor serà aquesta pregunta professional:

    Com podem preparar un entorn de desenvolupament reproduïble que permeta editar, construir i mantindre programes?

    Un IDE reuneix un editor, eines de construcció, depuració, gestió de projectes i extensions en una mateixa interfície. Compararem un entorn lleuger i extensible amb un entorn orientat a projectes Java i a la integració de ferramentes. No totes les extensions o plugins són necessaris: instal·larem només el que necessitem, documentarem les versions i justificarem les decisions.

    Dades de la unitat

    Element Referència
    Duració de referència 15 hores
    Resultat d’aprenentatge RA2
    Pes de referència 20 %
    IDE del laboratori Visual Studio Code i IntelliJ IDEA
    Producte final Informe comparatiu i demostració d’un entorn reproduïble
    Forma de treball Individual, parelles i equips de tres

    Què aprendràs

    • Instal·lar i verificar Visual Studio Code i IntelliJ IDEA, respectant l’edició i la llicència de cada instal·lació.
    • Afegir, configurar i eliminar mòduls, connectors i extensions.
    • Personalitzar l’editor i automatitzar tasques habituals del projecte.
    • Configurar canals d’actualització i comprovar la compatibilitat abans d’actualitzar.
    • Generar executables o artefactes executables a partir de codi de llenguatges diferents en un mateix IDE.
    • Construir el mateix projecte Java amb Visual Studio Code i IntelliJ IDEA i comparar el resultat.
    • Identificar característiques comunes i específiques de diversos entorns.
    • Deixar una guia de reproducció amb versions, ordres, proves i incidències.

    Itinerari de treball

    Consulta l’índex de la UP1 per veure l’ordre recomanat, la seqüència de sessions i les evidències. La teoria i les activitats també estan disponibles des d’aquesta pàgina.

    Materials teòrics

    Bloc Contingut
    1. Què és un IDE Components i diferències entre Visual Studio Code i IntelliJ IDEA.
    2. Instal·lació JDK, extensions, plugins, versions i instal·lació verificable.
    3. Mòduls i extensions Catàlegs, dependències, configuració i eliminació segura.
    4. Personalització i automatització Perfils, format, tasques, terminals i construccions repetibles.
    5. Actualitzacions Versions, canals, còpies, compatibilitat i recuperació.
    6. Construcció d’executables Llenguatges, compiladors, intèrprets, paquets i artefactes.
    7. Comparació d’entorns Elements comuns, diferències i criteris de selecció.

    Activitats i autoavaluació

    Activitat Producte
    1. Laboratori d’instal·lació Fitxa d’instal·lació de VS Code i IntelliJ IDEA.
    2. Taller de mòduls i automatització Perfil de treball, extensió, tasca automatitzada i registre d’actualització.
    3. Construcció i comparació Executables/artefactes de diversos llenguatges i el mateix projecte en dos IDE.
    Autoavaluació de la UP1 Qüestionari individual i repte final.

    Evidències avaluables

    Evidència Producte Criteris principals
    1. Laboratori d’instal·lació Fitxa amb requisits, versions, llicència i verificació RA2.a
    2. Configuració de l’entorn Perfil, mòduls, personalització, automatització i actualització RA2.b, RA2.c, RA2.d
    3. Construcció multiplataforma Registre de comandes, executables, proves i incidències RA2.e, RA2.f
    4. Informe comparatiu Matriu de característiques i defensa de la proposta RA2.g

    Resultat d’aprenentatge i criteris

    RA2. Avaluar entorns integrats de desenvolupament, analitzant les seues característiques per a editar codi font i generar executables.

    Criteri Què hauràs de demostrar
    RA2.a Instal·lar entorns de desenvolupament, propietaris i lliures.
    RA2.b Afegir i eliminar mòduls a l’entorn de desenvolupament.
    RA2.c Personalitzar i automatitzar l’entorn de desenvolupament.
    RA2.d Configurar el sistema d’actualització de l’entorn de desenvolupament.
    RA2.e Generar executables a partir de codi font de diferents llenguatges en un mateix entorn de desenvolupament.
    RA2.f Generar executables a partir d’un mateix codi font amb diversos entorns de desenvolupament.
    RA2.g Identificar les característiques comunes i específiques de diversos entorns de desenvolupament.

    Abans de començar

    Consulta la llicència i els requisits de cada producte. En el laboratori treballarem amb Visual Studio Code i IntelliJ IDEA; la fitxa indicarà si IntelliJ IDEA funciona amb les funcions bàsiques gratuïtes o amb les funcions avançades d’Ultimate mitjançant subscripció o llicència educativa. No instal·les programari d’origen dubtós ni actives llicències amb claus compartides. Treballa amb projectes de prova, no publiques credencials i conserva les versions i les ordres que permeten repetir el laboratori.
