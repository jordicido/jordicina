    Activitat 1. Laboratori d’instal·lació

    Context

    Una empresa incorpora una persona desenvolupadora i necessita preparar un ordinador nou amb dos IDE. El procediment ha de quedar documentat perquè el puga repetir una altra persona sense dependre de captures incompletes.

    Objectiu

    Instal·lar Visual Studio Code i IntelliJ IDEA, configurar Java i Maven i demostrar que els dos entorns poden obrir i construir un projecte Java mínim.

    Criteris d’avaluació treballats

    • RA2.a: instal·lació d’entorns de desenvolupament amb modalitats de llicència diferents.

    Tasca

    1. Identifica el sistema operatiu, l’arquitectura, l’espai disponible i la memòria.
    2. Instal·la el JDK i Maven i registra java --version i mvn --version.
    3. Instal·la Visual Studio Code i IntelliJ IDEA des de les fonts oficials.
    4. Afig a VS Code el suport necessari per a Java.
    5. Obri el mateix projecte Java amb Maven en els dos IDE.
    6. Construeix i executa el programa en cada entorn.
    7. Registra qualsevol incidència i la solució aplicada.

    Requisits

    • Els dos IDE han de ser Visual Studio Code i IntelliJ IDEA.
    • El projecte ha de contindre codi font Java i un pom.xml.
    • La fitxa ha d’indicar versions, fonts, llicències o modalitats d’ús.
    • La prova ha d’incloure una ordre de versió i un resultat de construcció.
    • No s’han d’incloure credencials, tokens ni dades personals.

    Lliurament

    • fitxa-instal·lacio.md.
    • Taula de requisits i versions.
    • Captures o logs justificats de la detecció del JDK i de Maven.
    • Codi font del programa mínim i pom.xml.
    • Conclusió sobre les diferències inicials entre els dos IDE.

    Evidències d’aprenentatge

    El professorat podrà observar que l’alumnat identifica els prerequisits, instal·la els dos entorns, diferencia l’IDE de les eines del llenguatge i obté una primera construcció verificable.

    Criteris de correcció

    • La instal·lació és reproduïble i utilitza fonts fiables.
    • Les versions i llicències estan identificades.
    • Java i Maven estan configurats correctament.
    • El mateix projecte es pot obrir i executar en els dos IDE.
    • Les incidències estan descrites amb evidències i no només amb una conclusió.

    Ampliació

    Compara la instal·lació en dos sistemes operatius i identifica quines parts són comunes i quines depenen del sistema.
