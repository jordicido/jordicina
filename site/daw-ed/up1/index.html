    UP1. Entorns integrats de desenvolupament

    Resultat d’aprenentatge

    RA2. Avaluar entorns integrats de desenvolupament, analitzant les seues característiques per a editar codi font i generar executables.

    Criteris d’avaluació

    Criteri Enunciat
    RA2.a S’han instal·lat entorns de desenvolupament, propietaris i lliures.
    RA2.b S’han afegit i eliminat mòduls a l’entorn de desenvolupament.
    RA2.c S’ha personalitzat i automatitzat l’entorn de desenvolupament.
    RA2.d S’ha configurat el sistema d’actualització de l’entorn de desenvolupament.
    RA2.e S’han generat executables a partir de codi font de diferents llenguatges en un mateix entorn de desenvolupament.
    RA2.f S’han generat executables a partir d’un mateix codi font amb diversos entorns de desenvolupament.
    RA2.g S’han identificat les característiques comunes i específiques de diversos entorns de desenvolupament.

    Què aprendrem?

    Treballarem amb Visual Studio Code, IntelliJ IDEA i Java. Aprendrem a preparar un entorn que una altra persona puga reproduir, a gestionar extensions i plugins, a automatitzar una construcció i a comparar les decisions de dos IDE.

    Per cobrir RA2.e utilitzarem un segon llenguatge de la mateixa família tecnològica, Kotlin, només en la pràctica de construcció amb IntelliJ IDEA. El projecte principal i la comparació entre IDE es faran amb Java i Maven.

    Continguts

    Bloc Contingut
    1. IDE i entorn de treball Components, llicències i diferències entre VS Code i IntelliJ IDEA.
    2. Instal·lació verificable JDK, Maven, versions, fonts oficials i primera construcció.
    3. Mòduls, extensions i plugins Instal·lació, configuració, desactivació i eliminació.
    4. Personalització i automatització Perfils, configuració del projecte, tasques i Maven.
    5. Actualitzacions i recuperació Canals, compatibilitat, còpies i pla de retorn.
    6. Construcció d’executables Java, Kotlin, JAR i construcció del mateix projecte.
    7. Comparació d’entorns Característiques comunes, específiques i criteris de selecció.

    Activitats

    Activitat Tipus Evidència principal
    1. Laboratori d’instal·lació Guiada i d’aplicació Fitxa de versions, llicències i primera construcció.
    2. Configuració i manteniment Pràctica de laboratori Extensions/plugins, perfil, tasca i actualització documentada.
    3. Construcció i comparació Avaluable Artefactes Java/Kotlin, JAR en dos IDE i matriu comparativa.
    Autoavaluació Individual Respostes raonades i repàs dels set criteris.

    Seqüència didàctica

    La UP1 disposa de 10 hores. La seqüència combina explicació, laboratori, construcció, comparació i revisió:

    Fase Treball
    1 Necessitats d’un IDE, llicències, instal·lació i verificació.
    2 Extensions, plugins i configuració del projecte.
    3 Automatització, actualització i recuperació.
    4 Construcció Java/Kotlin i comparació del mateix projecte en VS Code i IntelliJ IDEA.

    Cobertura dels criteris

    Criteri Teoria Activitats
    RA2.a 01, 02 Activitat 1
    RA2.b 03 Activitat 2
    RA2.c 04 Activitat 2
    RA2.d 05 Activitat 2
    RA2.e 06 Activitat 3
    RA2.f 06, 07 Activitat 3
    RA2.g 01, 07 Activitat 3

    Producte final

    El lliurament final és un repositori o carpeta de laboratori amb les configuracions necessàries, el codi font, els artefactes generats, els logs o captures justificades i una comparació tècnica de VS Code i IntelliJ IDEA. No s’hi han d’incloure credencials, tokens ni llicències personals.
