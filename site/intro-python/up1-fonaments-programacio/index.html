    UP1. Primers passos amb Python

    Presentació

    En aquesta unitat prepararem l’entorn de treball i aprendrem a llegir i escriure programes lineals molt senzills amb variables. El fil conductor serà aquest model:

    Entrada de dades → Variables i processament → Eixida de resultats

    Començarem amb Python, Visual Studio Code i el primer projecte. Després estudiarem l’estructura d’un programa, print(), els tipus bàsics, les variables, input() i les operacions elementals. La teoria serà breu i la major part del temps es dedicarà a executar, modificar i explicar codi.

    En aquesta UP no treballarem encara condicions, bucles, llistes ni funcions. L’objectiu és consolidar el model mental bàsic que necessitarem en les unitats següents.

    Dades de la unitat

    Element Referència
    Duració de referència 6 hores
    Resultat d’aprenentatge RA1
    Pes de referència 10 %
    Criteris treballats RA1.a–RA1.i
    Producte final Entorn preparat i sèrie de programes lineals explicats i verificats
    Forma de treball Individual, parelles i comprovació individual

    Què aprendràs

    • Identificar les instruccions i els blocs bàsics d’un programa.
    • Crear un projecte i una estructura de carpetes ordenada.
    • Utilitzar Visual Studio Code, la terminal i l’intèrpret de Python.
    • Reconéixer els tipus int, float, str i bool.
    • Crear, consultar, modificar i combinar variables.
    • Llegir dades amb input() i convertir-les quan calga.
    • Mostrar resultats amb print() i f-strings.
    • Distingir literals i constants per convenció.
    • Utilitzar operadors en expressions i comprovar conversions explícites i implícites.
    • Introduir comentaris útils per documentar el codi.

    Itinerari de treball

    Consulta l’índex de la UP1 per seguir l’ordre recomanat, veure les sis sessions i consultar la cobertura dels criteris. La teoria i les activitats també estan disponibles des d’aquesta pàgina.

    Materials teòrics

    Bloc Contingut
    1. Què és un programa Instruccions, scripts, ordre d’execució i estructura entrada–processament–eixida.
    2. Preparació de l’entorn Python, Visual Studio Code, extensió, intèrpret i primer projecte.
    3. Eixida amb print() Text, nombres, variables, f-strings i presentació de resultats.
    4. Variables Assignació, consulta, modificació i noms descriptius.
    5. Tipus bàsics int, float, str, bool, literals i constants.
    6. Entrada amb input() Entrada de text i conversió amb int() i float().
    7. Operacions bàsiques Operadors, expressions, conversions i comentaris.

    2. Sèrie d’exercicis Exercicis progressius i programa final d’integració.
    Autoavaluació de la UP1 Preguntes de comprovació i llista de preparació per a la defensa.

    Resultat d’aprenentatge i criteris

    RA1. Reconéixer l’estructura d’un programa informàtic, identificant i relacionant els elements propis del llenguatge de programació utilitzat.

    Criteri Què hauràs de demostrar
    RA1.a Identificar els blocs que componen l’estructura d’un programa informàtic.
    RA1.b Crear projectes de desenvolupament d’aplicacions.
    RA1.c Utilitzar entorns integrats de desenvolupament.
    RA1.d Identificar els tipus de variables i la utilitat específica de cadascun.
    RA1.e Modificar el codi per crear i utilitzar variables.
    RA1.f Crear i utilitzar constants i literals.
    RA1.g Classificar, reconéixer i utilitzar els operadors en expressions.
    RA1.h Comprovar conversions de tipus explícites i implícites.
    RA1.i Introduir comentaris en el codi.

    Abans de començar

    Treballa amb Python 3 i Visual Studio Code instal·lats des de fonts oficials. No necessites cap llibreria externa. Utilitza noms de variables clars, conserva els fitxers de pràctiques i no inclogues dades personals o credencials reals en els exemples.
